故事芽源于一次亲子伴读：孩子喜欢漫画，家长希望文字更短、图像更清楚，还能听一句、读一句。我们先把故事、画面与朗读正文整理成可审阅的内容，再逐步实现创作工具。

**当前仓库交付内容方案、提示词、数据契约和检查脚本。** 首页封面是原创矢量概念图；尚无应用界面、生成插画或音频成品。完整候选建议存入私人仓库，素材范围见[素材与许可说明](docs/素材与许可说明v1.0.md)。

<a id="use-cases"></a>
## 从一个孩子的一章开始

- **家长整理材料**：确认章节发生了什么，区分原书事实、改编内容和教学化表达。
- **陪孩子读故事**：先看漫画，再指物认词、听读短句，最后分角色演一演。
- **为后续开发留清楚的输入**：固定角色、道具、句子ID和页面引用，让文字、图像与声音可以分别修改。

当前第一位读者设定为7岁中国儿童、英语初学，希望接近新概念第一册前13课；实际教材词表与已会词表尚未取得，课程匹配、新词数和独立阅读效果均待确认。

<a id="quick-start"></a>
## 开始阅读与审阅

1. 打开[第一章内容设计](docs/第一章内容设计v1.1.md)，先确认“孩子读什么、画面表现什么、音频读什么”。
2. 在唯一正文表审阅英文、中文、词数和角色，再检查五页引用与独立家长答案。
3. 后续创作参考[创作提示词手册](prompts/创作提示词手册v1.0.md)；开发任务参考[开发总提示词](prompts/开发总提示词v1.0.md)，按当轮授权选择任务。

文档可直接阅读，无需API或模型账号。要重复运行检查，在仓库根目录使用Python 3.12：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r 检查依赖v1.0.txt
.venv/bin/python scripts/仓库检查v1.0.py
```

检查只读本地候选文件，不发送书籍或儿童数据；Git索引检查与环境说明见[协作说明](docs/协作说明v1.0.md)。

<a id="workflow"></a>
## 一份正文，五页伴读

| 步骤 | 审阅产物 | 当前第一章的安排 |
| --- | --- | --- |
| 确认材料 | 事件摘要与待核验项 | 只保留样章已有角色与事件 |
| 固定形象 | 角色、道具与空间卡 | 獾、臭鼬、同一红箱子与绿门 |
| 登记正文 | 稳定ID、角色、英文和中文 | 15条句子／拟声＋3个词读单元 |
| 设计页面 | 分镜、词卡与活动引用 | 六格 → 大场景 → 词卡 → 听读 → 表演 |
| 准备朗读 | 顺序、英文正文与跟读空档 | 14次故事读句，每次计划留3秒 |
| 家长审阅 | 答案、修改点与未知项 | 原书、课程、实际新词与试读待确认 |

当前只有脚本设计，未生成音频、时间戳或实际时长。未来实现时，正文修改必须使旧音频失效，避免气泡与声音读出不同的句子。
