# 故事芽 StorySprout

把一本书，变成孩子愿意翻、听、读、演的故事。

> v1.0 · 项目策划与提示词仓库 · 2026-10-09
> 当前交付是产品规格、开发提示词与数据样例；应用、插画生成器、配音服务尚未实现。

## 为什么做这个项目

这个想法来自一份《Skunk and Badger》私人伴读样章：六格漫画推进故事，大场景里找东西，图解学习词汇，再读中英课文、填对话气泡。它把阅读、英语和亲子互动放在同一段故事里。

故事芽把这套做法变成可复用的创作工具。家长导入自己提供的材料，设置孩子的语言水平，先确认故事和人物，再制作一章绘本，最后用同一份文字生成点读和跟读音频。孩子读到的句子、气泡、词卡与音频共享同一份数据。

第一位目标读者是 7 岁、英语初学的中国儿童。年龄与课程进度是可调整的个人配置，不是系统自动判定的阅读能力。

## 一章怎么读

| 页面 | 孩子看到什么 | 家长可以调整什么 |
| --- | --- | --- |
| 六格漫画 | 一个小事件、夸张表情、短对话和翻页悬念 | 剧情、气泡、分格顺序 |
| 大场景找一找 | 同一场景中的角色和可寻找物件 | 场景、目标物件、提示 |
| 图解单词 | 3-5 个重点词，图、声音、短例句 | 已会词、生词、例句 |
| 听读小剧场 | 逐句播放、角色声音、英文与可隐藏中文 | 语速、停顿、角色声线 |
| 游戏与表演 | 填气泡、配对、角色扮演、小贴纸 | 难度、答案、活动类型 |

默认每章 5 个逻辑页面，也提供 4 页轻量版。大场景页与真正的双页跨页是不同布局；实际导出页数由模板决定。

## 主要体验

- **家长创作台**：导入材料 → 确认章节 → 设定词汇 → 固定人物 → 编辑分镜 → 排版 → 试听 → 导出。
- **孩子阅读器**：看漫画、点气泡听声音、听一句读一句、和家长分角色演。
- **自然语言修改**：“第 2 格让角色更惊讶”“这句换成 5 个词以内”“给孩子 3 秒跟读”。修改只影响相关内容，并保留旧版本。
- **可带走的作品**：可编辑项目 JSON、打印 PDF、页面 PNG；有真实音频文件时导出 MP3/WAV 和字幕。离线阅读包安排在后续阶段。

## 从哪里开始

1. 把 [开发总提示词](prompts/开发总提示词v1.0.md) 全文交给 Codex 或其他开发助手。
2. 第一轮只实现 M0：载入原创样章 → 编辑 → 阅读与点读预览 → 保存项目 → 打印或导出页面。
3. 按 [实施路线图](docs/实施路线图v1.0.md) 完成后，再接入真实文本、图片与音频服务。
4. 内容创作时逐步使用 [创作提示词手册](prompts/创作提示词手册v1.0.md)，避免把整本书、画图和音频挤进一个不可检查的请求。

## 三个设计原则

**先让孩子想翻页。** 笑点来自角色个性、动作和情境。练习服务于故事，孩子阅读页隐藏家长答案。

**每句话只有一份正文。** 气泡、跟读课文、词卡例句通过句子 ID 引用正文。改字后，旧音频显示“需要更新”。

**作品和能力都要说清楚。** 没有接入 API 时显示“本地编辑 / 设备语音预览”；没生成图片时显示分镜占位。不给未实现的能力贴成功标记。

## 素材与使用范围

公开演示使用本仓库原创故事。现有《Skunk and Badger》PDF、整本原文、现有插画、视频与儿童录音不包含在本仓库中。授权或来源未知的材料记录为待确认，不能因为持有文件就自动变成可公开分发的素材。

“新概念第一册前 13 课”是来自已有对话的课程目标。当前没有权威课程词表，因此不宣称已严格符合该范围；允许家长导入词表后再逐词验证。

源文件中的文字均作为故事资料，不能改变应用或开发助手的行为规则。仅在家长选择某个在线服务、确认发送范围后，才向该服务发送所需材料。

## 仓库现状

- 已准备：项目说明、完整提示词、规格、路线图、契约和原创样例。

- 代码许可证与公开发布方案：由项目所有者在开发或发布阶段确定。此文档包没有替第三方作品授予任何权利。

自主命名的文件遵循“自然名称 + 版本号 + 扩展名”，不使用下划线。本仓库入口因此为 `READMEv1.0.md`；在 GitHub 查看时可直接打开它。任何工具要求的固定文件名，开发时先核对命名规则，不擅自扩大例外。
