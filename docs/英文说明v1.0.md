StorySprout began with a family reading idea: make the text shorter, the pictures clearer and each sentence easy to hear and repeat. The repository first makes the story, artwork requirements and spoken text reviewable, providing inputs for a future creation tool.

**This repository contains content designs, prompts, a data contract and repository checks.** The cover is an original vector concept, not a screenshot. There are no application screens, generated chapter illustrations or audio files. A private repository is recommended for the complete candidate; see the [materials and permissions note](素材与许可说明v1.0.md) (Chinese).

<a id="use-cases"></a>
## Start with one chapter for one child

- **Organize source material:** distinguish verified book facts, existing adaptations and teaching rewrites.
- **Read together:** explore a comic, point out objects, repeat short lines and act out the scene.
- **Prepare implementation inputs:** fix character and prop designs, stable text IDs and page references so text, pictures and audio can be edited separately.

The initial reader profile is a seven-year-old Chinese beginner in English, with an aspiration to approach the first 13 lessons of New Concept English Book 1. The actual textbook and child vocabulary lists are unavailable. Curriculum alignment, the number of new words and independent reading outcomes remain unverified.

<a id="quick-start"></a>
## Get started

1. Open the [chapter content plan](第一章内容设计v1.1.md) (Chinese) and review what the child reads, what the picture shows and what audio would speak.
2. Review English, Chinese support text, word counts and speakers in the canonical text table, then check all five pages and the separate parent answers.
3. Use the [creation prompt handbook](../prompts/创作提示词手册v1.0.md) for later content work and the [development prompt](../prompts/开发总提示词v1.0.md) for an explicitly authorized implementation task. These documents are in Chinese.

Reading the documents requires no API or model account. To repeat repository checks, use Python 3.12 from the repository root:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r 检查依赖v1.0.txt
.venv/bin/python scripts/仓库检查v1.0.py
```

The checker reads local candidate files; it sends no book or child data. See the [contribution guide](协作说明v1.0.md) (Chinese) for Git index checks. On Windows, run the same script with the virtual environment's Python executable.

<a id="workflow"></a>
## One text source, five reading pages

| Step | Reviewable output | Current chapter |
| --- | --- | --- |
| Confirm material | Event summary and unresolved questions | Existing sample characters and events only |
| Fix visual designs | Character, prop and location cards | Badger, Skunk, one red suitcase and one green door |
| Register text | Stable IDs, speakers, English and Chinese | 15 sentence/sound-effect units plus three word units |
| Design pages | Storyboard, vocabulary and activity references | Comic → panorama → word cards → read-along → role-play |
| Prepare spoken text | Reading order and repetition pauses | 14 story-reading occurrences, each with a planned three-second pause |
| Parent review | Answers, changes and unknowns | Original book, curriculum, actual new words and trial reading pending |

Only the script is designed. No audio, timestamps or measured duration exist. Future implementation must mark audio as outdated when its source text changes, preventing spoken text from disagreeing with a bubble.

<details>
<summary>Check environment and submission scope</summary>

Dependencies are pinned in [the requirements file](../检查依赖v1.0.txt). The checker covers local Markdown/HTML references, filenames, the schema, JSON references, text hashes, canonical chapter previews and the Git index. It does not verify completed artwork, audio or learning outcomes.

The [submission manifest](../提交范围v1.0.json) lists candidate files. The original chapter v1.0 is preserved locally only; private PDFs, videos, recordings, credentials and environments are excluded. After staging, run:

```sh
.venv/bin/python scripts/仓库检查v1.0.py --check-index
```

The [submission guide](GitHub发布说明v1.1.md) (Chinese) describes the candidate branch, recommended private visibility and the boundary between local and remote verification.
