# 实施路线图 v1.0

状态：规划。按可检查成果拆分，未承诺工期。每个阶段通过后再扩展，避免一次承诺整本书、全部格式与所有语音能力。

## M0 · 一章能编辑、能读、能保存

| 任务 | 依赖 | 交付与完成条件 |
| --- | --- | --- |
| 导入原创数据与引用检查 | 数据契约 | 原创样例可显示，错误 ID 被拒绝 |
| 五页渲染与响应式阅读器 | 解析器 | 手机逐格、平板整页，内容可读 |
| 家长文字编辑、顺序与撤销 | 渲染器 | 修改只影响目标，并更新相关正文引用 |
| IndexedDB 保存与 JSON 交换 | 项目模型 | 刷新恢复，导入导出可继续编辑 |
| 设备语音与逐句跟读 | utterances | 主动点击播放，无声音时可继续看书；切页取消 |
| 核心词卡与活动答案分离 | 数据引用 | 点读词卡；儿童版不见答案 |
| PNG 与打印页面 | 排版 | 实际检查中文、气泡、方向与裁切 |

M0 不依赖付费模型。图像可以是清楚标记的分镜占位；真实插画与音频文件尚不存在时，页面必须显示对应状态。

## M1 · 制作一个真正的原创或授权样章

| 任务 | 依赖 | 交付与完成条件 |
| --- | --- | --- |
| 材料分段与故事来源索引 | M0 | 原始段落可定位，缺口不会被补成原书事实 |
| 词表与句型检查 | 阅读档案 | 全章文字可检查，未知词表状态诚实 |
| 文本生成适配器 | 来源与发送范围 | 有 JSON 验证、人工可编辑，失败保留草稿 |
| 人物参考与图像适配器 | 人物卡、分镜 | 一章实际插画；核心道具跨页一致 |
| SVG/HTML 可编辑文字层 | 真实插画 | 改字不重画，气泡和图像分别保存 |
| TTS 适配器与媒体持久化 | 确认版正文 | 真实音频、逐句时长、试听和失效检查 |
| 合成音频与字幕 | 逐句音频 | 故事版与跟读版分别计时，文件可播放 |
| 确定版式 PDF 与项目媒体包 | 所有资源 | 完整可编辑项目，导出检查明确 |

接入 MiniMax 或其他服务前核对官方接口、可用区域、声音、价格和预算。若配置不齐，继续手动创作与导入媒体，并标记生成能力待配置。

## M2 · 整本书与亲子体验

跨章复用人物与词汇、连续阅读、自然语言 EditPatch 完整覆盖、孩子录音在本设备回放、离线阅读包、家长观察记录。先完成真实断网检查，再宣传离线；录音不作为自动能力评分。

## M3 · 根据家庭使用再选择

视频化、更多语言与模板、教师工作区、朗读评估。先确认用户是否实际需要，避免以尚未验证的“智能评分”作为产品卖点。

## 可以直接复制成 GitHub 议题

每个议题写：用户触发 → 当前问题 → 预期行为 → 范围 → 完成条件 → 证据。

- **载入原创五页并切换阅读视图**：无密钥打开原创故事，家长可编辑，孩子可翻页；检查手机和平板尺寸。
- **正文统一与编辑保存**：修改一句后气泡和课文一致，刷新恢复，JSON 重新导入仍可编辑。
- **逐句跟读播放状态**：连续点击、暂停、切页均无叠播；等待可以取消或恢复。
- **图文分层与局部重生成**：改字保留画面；改表情仅更新目标格；资源失效范围可查看。
- **真实音频与字幕导出**：导入或生成实际媒体，测时长、合成、检查字幕；缺文件时不伪装下载成功。
- **儿童版打印与答案分离**：中文清晰、无裁切、儿童版隐藏答案，家长版可选答案。
- **私有资料与在线服务范围**：本地编辑不外传；服务、章节、预算可确认；导出不含密钥和录音。

## 首版结束后的迭代依据

收集 1-3 次家庭实际试读观察，不伪造次数或反馈。根据具体卡点修改：某句读不懂、某页太挤、某项活动无聊、角色声音混淆。没有观察时继续写“待试读”，不写“广受儿童欢迎”。
