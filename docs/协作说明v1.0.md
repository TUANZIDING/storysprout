# 协作说明 v1.0

当前仓库交付文档、内容设计、数据契约与检查脚本；Web应用尚未实现。请先读根目录 README.md，再按当前任务修改，不把开发总提示词当成本轮自动执行授权。

## 修改规则

- 自主命名文件使用自然名称、版本号和扩展名，不使用下划线；既有文件不批量改名。
- README.md 与 .gitignore 是工具固定入口；READMEv1.1.md 保存当前首页快照，README.md 应与该快照一致。
- 修改正文时以句子ID登记处为准，同步气泡、词卡、课文与活动预览；不要只改其中一处。
- 原书事实、已会词表、教材匹配、媒体检查和试读结果分开记录，缺证据就保留待核验。
- 文档迭代保留旧版本并增加新版本；在首页和提交范围清单中更新当前入口。历史检查报告只代表其记录日期。
- 用原创最小示例报告问题，不上传私人PDF、原书全文、儿童录音、密钥或本机路径。

## 贡献说明

提交描述写明具体问题、改变后的行为、验证和剩余限制。修正文案不用制造镜像测试；数据引用、媒体失效、播放状态等实际逻辑在实现时应有针对性验证。

修改提交范围后运行仓库检查。新增文件必须加入 提交范围v1.0.json；仅在本机保留的材料明确列为 localOnly，并由 .gitignore 排除。

```sh
python scripts/仓库检查v1.0.py
python scripts/仓库检查v1.0.py --check-index
```

第二条需要先暂存本次应提交文件，检查Git索引是否恰好等于清单。不要使用父目录的Git仓库来提交本项目，也不要将所有本地分支一起推送。

首页默认中文加完整英文首页，能力状态与链接必须一致。后续图片、音频和界面需标明概念、示例或实际结果。
