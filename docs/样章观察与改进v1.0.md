# 样章观察与改进 v1.0

观察日期：2026-10-09。来源是用户提供的 `Ch01_Comic_Sample.pdf`、Hark 对话截图及用户提供视频。现有源文件没有被重命名、修改或复制进仓库。

## 观察范围

- PDF：提取并阅读全部 5 页文字，渲染并检查全部 5 页画面。元数据标题是 Skunk & Badger 第 1 章漫画样章，作者字段为 Hark；元数据不是内容准确性证明。
- Hark：依据用户截图和随截图提供的可访问性文字。未取得完整历史对话、完整创作提示词或其他附件；“每章新词不超……”之后的数值在提供内容中不完整。
- 视频：文件时长约 25 分 32 秒、1920×1080，包含音轨。只查看第 60、720、1440 秒的画面，没有完整播放、转录或试听，所以不能评价实际发音、配乐或同步质量。
- 没有原书第一章文本，因此没有核验改编是否忠实原书、是否遗漏关键人物或情节。

第 2 页是单个横向 PDF 页面，不能据此称为真正的双页跨页。Hark 对话中的四页方案与实际五页输出不同；项目默认采用已经呈现的五页结构，并另设四页模板。

## 已观察到的优点

格号明确，漫画动作连续；每格有突出表情或声音效果。词卡复用漫画图像，课文和亲子表演围绕同一小事件。画面中的找物与填气泡可以直接转成互动热点和可编辑文字层。

这些是对当前样章形式的观察，不代表儿童已经喜欢、试读完成或学习效果已验证。

## 需要补入系统的检查

| 观察 | 影响 | 规则 |
| --- | --- | --- |
| 第 3 页有 5 个重点词，第 4 页词表有 12 项，第 2 页又有其他找物词 | 重点词、生词和所有出现词混在一起时，家长难以控制负担 | 分开统计 focus / known / new / names / sound effects；整章统一去重 |
| 课文含 has、loves、shuts 等形式，未提供课程词表 | 不能凭“前13课”标签断言全部达标 | 使用家长词表与允许句型验证；保留未验证状态 |
| 文字要求红色箱子，画面箱子呈橙棕色或棕色；第 2 页可见两只箱子 | 颜色题与物件数量可能让孩子困惑 | 固定道具颜色和数量，跨页检查，图完成后再出题 |
| 第 5 页家长答案在孩子页面底部可见，字号很小且倒置 | 屏幕阅读仍可能看见；也不方便家长查阅 | 答案独立数据与显示权限，儿童打印版隐藏 |
| “Is Skunk a new friend?” 依据臭鼬自称 | 自称和獾实际接受关系不同，答案可能含糊 | 问题绑定可观察事实或明确台词，允许家长改写 |
| 竖横方向混用 | 打印、缩略图和移动端体验需要专门处理 | 明确屏幕与打印模板，支持大图专页预览 |
| 插画里有细小装饰文字 | 文字不可控，不能成为可靠词卡素材 | 图片尽量无正文，课程文字由程序统一排版 |

没有原书文本，不能把样章里“关门”等事件评为原书事实或原书错误。语言是否超出具体课程也未逐词核验，只能指出待验证项。

## 视频抽样带来的需求

60 秒画面：角色介绍，左侧插画、右侧英文段落，当前句以黄色底突出；其中房子与 Aunt Lula 关联。720 秒画面：第 6 章标题与中文意思。1440 秒画面：大号英文单词 breakfast、中文“早餐”与“轮到你”提示。

这支持把故事讲解、中文帮助、句子强调、单词跟读与练习留白加入产品需求。它不证明视频使用了哪家 TTS、是否逐句精确对齐，或孩子已经跟读。

房子的居住者、所有者等关系应在后续拿到原文时单独确认；不能将 PDF 的“He has ...”与视频介绍自动合并成确定设定。

## 私人项目迁移方式

1. 先索引现有 PDF 的文字与画面，明确哪些是插画底图、哪些是后加文字。
2. 人工确认角色卡、房子关系、箱子颜色与数量。
3. 把句子放进统一 utterances，建立 page/panel 引用。
4. 将词表分成重点与新增，隐藏答案；保留原版供比较。
5. 在确认版文字上制作音频，不从图片 OCR 结果直接配音。

本次没有执行上述迁移、没有生成新的獾与臭鼬图片或音频。公开仓库以原创示例演示通用流程，不附私人参考媒体。
