```sh
python scripts/仓库检查v1.0.py
python scripts/仓库检查v1.0.py --check-index
```

两种检查均已在本地通过。索引检查要求所有候选已暂存，并拒绝候选工作文件与暂存内容不同的情况。普通检查可用于没有.git目录的源码解压包；索引检查需要本项目Git仓库。

在内存复制的样例上进行8个反例检查，均按预期拒绝：无效气泡引用、重复正文ID、错误词数、过期正文哈希、没有素材却标ready的音频、错误填空答案、与正文不同的第一章预览、重复JSON键。没有改动真实示例或第一章正文。

本检查脚本验证当前候选的结构与引用；它不证明实际图片上物件已存在、实际音频能播放、课程匹配或儿童学习效果。
