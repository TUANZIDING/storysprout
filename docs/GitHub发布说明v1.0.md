## 推荐仓库信息

名称：`storysprout`（暂定，发布时再检查可用性）。

描述：A family story-making workspace for editable children's comics, graded bilingual reading, and sentence-by-sentence read-along audio.

中文介绍：将用户提供的故事材料整理为可编辑的儿童漫画绘本，支持双语辅助、点读、跟读与亲子角色扮演。

标签建议：picture-book、comics、read-along、text-to-speech、bilingual-reading、local-first、family-learning。

## 可直接粘贴的仓库介绍

```text
StorySprout（故事芽）是面向家庭的儿童故事创作项目。
它探索如何将用户提供的材料整理成多格漫画、大场景找物、图解词汇、逐句听读和亲子活动，让图、文字和音频共用同一份可编辑内容。

当前仓库包含产品设计、开发与创作提示词、数据契约、原创故事样例及分阶段验收方案。Web 应用与在线图片/配音服务尚未实现。
首个阶段目标是一章的编辑、阅读、保存和导出闭环；后续再接入真实生成服务。

私人伴读材料与公开软件演示分开管理。公开演示使用原创故事，用户导入材料需要记录来源与使用范围。
```
