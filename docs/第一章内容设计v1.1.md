# 《獾和臭鼬》第一章内容设计 v1.1

日期：2026-10-10。仓库收尾版：仅去除本机路径并更新版本说明，内容与v1.0一致。状态：一期初步内容方案，供家长审阅；尚未修图、排版或制作音频。

## 1. 本章目标、剧情与来源边界

**一句话目标：** 孩子借助敲门相遇的六格漫画，辨认獾与臭鼬，练读短对话，并在同一场景里认出 rock、door、suitcase。

**剧情摘要：** 獾在屋里看石头，敲门声响起。臭鼬提着手提箱来打招呼，自称獾的新朋友。獾露出不情愿的表情并关门，臭鼬继续呼唤；大场景承接现有样章的再次敲门，臭鼬要求开门，獾在窗边回应。故事到这里结束，不补写和解、入住、房屋归属或下一章情节。

上述事件取自**已有改编样章**的第1、2页；它们是“PDF中已有内容”，统一标记为 **原书待核验**。臭鼬的“新朋友”是角色自称，不等于獾已认可这段关系。角色外观和道具颜色是本方案的视觉固定设定，不作为原书文字事实。

材料已阅读：项目 README、样章观察、创作提示词及数据与音频协议；核对第一章 PDF 全部5页文字，并查看对应渲染画面。PDF 来源：用户提供的 `Ch01_Comic_Sample.pdf`（私人参考文件，不随仓库分发）。来源文件保持原样。项目文档中的开发计划不构成本轮执行任务。

### 读者与语言设定

- 默认7岁中国儿童、英语初学，希望接近新概念第一册前13课的学习进度；**实际教材词表未取得，课程匹配待核验**。
- 每个英文气泡不超过8词；中文用简短口语解释。气泡内有两句时，合计检查8词上限。
- 重点教学词仅 rock、door、suitcase；Badger、Skunk 作为角色名称单列。
- 已会词表未提供，因此“复习词”只是候选分类，**实际新词数量待确认**；不能把3个重点词写成“全章仅3个新词”。
- 保留剧情需要的短表达，删去额外的房屋所有权叙述和第三人称动作课文；关门等动作主要由画面与中文辅助说明。

### 第2页：大场景与3个找物目标

承接第1页门已关闭：臭鼬仍在门外，红箱子放到自己脚边，再次敲门；獾从窗内看着他。既有小鸡、猫、蜗牛、蝴蝶若保留，只作低干扰背景，不参与本轮找物和词表。

画面内对话顺序：气泡1 Skunk 引用 〔ch01-s12〕Open the door!（开门呀！）；气泡2 Badger 引用 〔ch01-s13〕Go away, Skunk!（走开，臭鼬！）。两泡各3词，按上到下排列并标1、2。再次敲门的动作／拟声复用 ch01-s03；中文页头可写“门又响了”，只作辅助。

孩子指令：**找一找，用手指指出石头、门和手提箱。** 清单只保留 rock、door、suitcase 三项，不问关系或情绪是否“对/错”。

## 5. 词汇与额外表达的边界

| 分类 | 本章内容 | 如何使用／当前确认状态 |
| --- | --- | --- |
| 重点教学词 | rock、door、suitcase | 3张词卡、3个找物目标、填空复现；这是教学选择，不是已知的新词总量 |
| 角色名称 | Badger、Skunk | 首次出现给中文“獾／臭鼬”；按角色名称单列，仍计入气泡词数和阅读负担 |
| 候选复习词与句型 | I am…、Hello…、Here is my…、This is…；其中的 I、am、hello、here、is、my、this、a、the | 希望用于重复短句；是否已会全部待家长词表确认，不标“已掌握” |
| 剧情所需额外表达 | love、rocks；Knock, knock!；Who is it?；your、new、friend；Oh no!；Open the door!；Go away, Skunk! | 为保留现有样章的兴趣、敲门、呼唤、自称与拒绝，单列解释，不另增教学词卡 |
| 实际新词 | 待确认 | 需取得孩子已会词表，并对全章出现词去重、核对词形后统计；目前不能给具体数量 |

rock 与 rocks 一并记录词形关系。Who is it? 用作敲门后的固定问句；Open the door! 和 Go away, Skunk! 是较直接的祈使表达，结合画面与中文理解即可，不宣称已属于教材范围。friend/new 只用于臭鼬自称，不能据此出“他们已经成为朋友吗”的确定答案题。

没有新增 house、has、loves、shuts、cat、snail、butterfly 等教学内容；背景存在某物不等于要孩子学习它的英文。灰色毛、橙围巾、红箱子是视觉描述，也不自动变成额外颜色词课。
