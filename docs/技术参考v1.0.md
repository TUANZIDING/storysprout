# 技术参考 v1.0

查看日期：2026-10-09。以下是本次方案使用的官方技术资料；它们支持可采用的接口和限制，不证明本项目已完成集成。实现前再次查看对应地区、模型、版本和价格。

| 资料 | 本方案如何使用 |
| --- | --- |
| [MiniMax 同步语音接口](https://platform.minimax.io/docs/api-reference/speech-t2a-http) | 作为可选 TTS 适配器。文档有音频格式、声音参数、字幕开关及句/词粒度；实际支持以实现时接口为准。返回媒体必须存入项目持久化资源，不能长期依赖临时 URL。 |
| [MDN Web Speech API](https://developer.mozilla.org/en-US/docs/Web/API/Web_Speech_API) | 设备语音预览。具体声音和执行位置取决于平台；不得把它描述成所有设备都完全离线。 |
| [MDN SpeechSynthesisUtterance](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance) | 点读正文的语言、语速、声音，以及播放结束事件。设备语音仅为预览，不代替可导出的音频文件。 |
| [MDN boundary event](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisUtterance/boundary_event) | 文档提示此事件兼容性有限，因此不能依靠它承诺所有浏览器都有逐词高亮。支持实际音频时间轴与句级降级。 |
| [MDN MediaRecorder](https://developer.mozilla.org/en-US/docs/Web/API/MediaRecorder) | 后续本设备录音，检测 MIME 支持、处理拒绝授权、停止后释放麦克风。浏览器录制文件不能默认改名为 MP3。 |
| [Vite 入门](https://vite.dev/guide/) | 提供轻量前端工作流。依赖组合在实际开发时验证并锁定，本文不虚构已完成安装。 |

不在这里固定 API 单价、声音 ID、账户区域或模型编号，因为这些可能随服务变化。接口参数应通过供应商适配层映射，不能污染故事正文。价格配置缺失时显示未知。

本地编辑、服务生成、设备语音预览、媒体文件导出是四种不同能力，要分别验收。语音识别、文字转录、朗读评估同样需要分别描述，不以识别结果代替发音准确度。
